📚 C# Exercises

A repository where I track my progress while studying C#. Every new topic I study becomes a project inside a themed folder, which keeps everything organized in one place and lets anyone follow my progress through the commit history.

⭐ Featured project

LibraryRentalSystem: a console application for managing book rentals, organized in layers (Entities, Repository, Service), with validations, business rules, and 38 documented test cases. See the project README.

📂 Contents
Folder	What's inside

LeetCode	LeetCode problems in C#, to practice logic and problem solving

Vetores	Exercises with vectors (arrays)

POO	Object-oriented programming: hands-on projects with classes, inheritance, composition, interfaces, exceptions, and collections
🗂️ How the repository is organized

Each folder is a study topic. Inside it, every exercise or study is a separate project, independent from the others.
